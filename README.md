# JayasriDayToDayWorkAssistant

Jayasri's daily work coach. Connect this repo in Claude and ask **"what should I do now?"** — you get one task, the steps, and where today stands.

- `week-plan.md` — this week's tasks, one a day
- `backlog.md` — alternatives when the day's task does not fit the mood
- `playbooks/` — step-by-step how-tos (schools, decks, videos, kit review)
- `progress.md` · `metrics.md` — weekly completion and the monthly numbers
- `updates/` — the dated log of what was done
- `visits.md` — the school-visit experience log · `templates/school-list.md` — the school tracker
- `.claude/skills/` — what-now · done · post-check · school-call · visit-log · sunday-review · numbers · hooks in `.claude/settings.json`

Targets live in `DailyUpdates/Jayasri/goals.md`; this repo is the daily layer under them. Rules for the coach: `CLAUDE.md`.
