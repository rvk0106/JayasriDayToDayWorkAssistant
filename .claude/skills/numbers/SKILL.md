# Numbers — record, then the gap

1. Ask for the number as she sees it on the screen: channel, subscribers, date. If a YouTube connector/MCP is available in the session, read it from there instead and say so.
2. Write it in `metrics.md`: the monthly row for this month (create it if missing); fees and batch sizes in the research table.
3. Say the gap in one line against the next target in the Targets table:
   "Skoolyng 120 subs · Dec 31 target 500 · 380 to go in 6 weeks ≈ 65 a week."
4. If a number is behind pace, the only question is "what is the next video?" — the cadence is the lever (`playbooks/clip-edit-and-post.md`).
5. Commit `metrics: <month>` and push.

Never invent or estimate a number. No report → the cell stays blank and the review says "not reported".
