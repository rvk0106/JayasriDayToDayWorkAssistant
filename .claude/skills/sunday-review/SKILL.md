# Sunday review — what went well first

1. **Count** from `week-plan.md`: planned rows this week · ✅ (swaps ↔ count as done) · ⏭ carried. Completion % = done ÷ planned.
2. **Say what went well first** — two specific things. Then what slipped, once, plainly.
3. **`progress.md`:** add the row (week · planned · done · % · tasks/day · what went well · note).
4. **Capacity rule** (`CLAUDE.md`): two weeks in a row ≥ 80% → next week has one more task a day · this week < 50% → fewer tasks, no blame. State which applies and why.
5. **Draft next week** in `week-plan.md`: one row per working day, from the targets' next milestones (`DailyUpdates/Jayasri/goals.md` dates in the "Targets this plan serves" block) and carried ⏭ items first. Mark it *draft — confirmed with Vamsi*.
6. **Month end** (last Sunday of the month or later) → `numbers` skill for the monthly row.
7. **Vamsi asking "how is Jayasri doing?"** → answer with the last 4 rows of `progress.md`: the trend and the completion %, no interpretation beyond what the capacity rule says.
8. Commit `plan: week N` and push.
