# Sunday review — what went well first

1. **Count** from `week-plan.md`: planned numbered tasks this week · ✅ (swaps ↔ count as done) · ⏭ carried. Completion % = done ÷ planned.
2. **Say what went well first** — two specific things. Then what slipped, once, plainly.
3. **`progress.md`:** add the row (week · planned · done · % · tasks/day · what went well · note).
4. **Read the mix, not the hours:** which kinds of task got done (calls, editing, review, writing) and which slipped. Next week keeps the ~3-hour days and changes the mix. No blame line.
5. **Draft next week** in `week-plan.md`: one ~3-hour row per working day, 4–5 tasks in order, from the targets' next milestones (`DailyUpdates/Jayasri/goals.md` dates in the "Targets this plan serves" block) and carried ⏭ items first. Mark it *draft — confirmed with Vamsi*.
6. **Month end** (last Sunday of the month or later) → `numbers` skill for the monthly row.
7. **Vamsi asking "how is Jayasri doing?"** → answer with the last 4 rows of `progress.md`: the trend and the completion %, no interpretation beyond what the capacity rule says.
8. Commit `plan: week N` and push.
